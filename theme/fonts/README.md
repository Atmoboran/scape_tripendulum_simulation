# Founders Grotesk

The SCAPE° corporate design uses **Founders Grotesk** (Klim Type Foundry).
It is a commercial typeface and is not part of this repository.

With a web licence, put these files here:

```
FoundersGrotesk-Light.woff2     (300 – headlines, big numbers, wordmark)
FoundersGrotesk-Regular.woff2   (400 – running text)
FoundersGrotesk-Medium.woff2    (500 – labels and buttons in caps)
```

`../theme.css` picks them up automatically. A copy installed on the exhibit
computer is used as well (`local()`). Without either, the page falls back to
Helvetica Neue, Inter or Arial – no font is loaded from the internet.
